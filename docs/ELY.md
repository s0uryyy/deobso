# Ely.by: настройка

1. Скачай authlib-injector из официального репозитория:
   https://github.com/yushijinhun/authlib-injector/releases/latest
2. Помести JAR в постоянное место, например `/home/me/minecraft/authlib-injector.jar`.
3. В JVM arguments отдельного профиля лаунчера добавь:
   ```text
   -javaagent:/home/me/minecraft/authlib-injector.jar=ely.by
   ```
   На Windows укажи свой путь. Это **аргумент JVM**, не аргумент Minecraft;
   injector не кладётся в `mods`. Для пути с пробелами нужны кавычки согласно
   правилам твоего лаунчера.
4. Запусти игру с deobso вместо IAS. Открой аккаунты → Add → Ely.by.
5. Введи e-mail/логин, пароль и при необходимости шестизначный TOTP-код.
   Пароль и код скрыты. После ответа сервера аккаунт добавится в обычный список.
6. Выбери аккаунт и Login. Сессия обновляется через Ely.by; скины и серверная
   авторизация идут через injector. Сервер должен поддерживать Ely.by.

Без указанного javaagent добавление Ely.by блокируется. Проверяется JVM-аргумент;
это подсказка конфигурации, а не доказательство совместимости конкретной версии
injector с конкретным Minecraft. Автоматическое скачивание/исполнение agent не
производится. Динамическая подмена провайдера в процессе игры не реализована.

## Безопасность и совместимость

- Пароль отправляется только POST-запросом по HTTPS на
  `https://authserver.ely.by/auth/authenticate`. 2FA передаётся в документированном
  формате `password:code`. HTTP redirects не разрешены.
- Сохраняются только зашифрованные access/client tokens. Для повторного входа
  используется `/auth/refresh`. Пароль не записывается в файл, логи или сообщения
  ошибок. Аппаратное шифрование — не защита от вредоносного ПО на этом компьютере.
- После переноса с другого ПК/профиля ОС аппаратное расшифрование может не работать:
  добавь Ely.by-аккаунт заново. Ошибка refresh также может требовать повторного входа.
- Injector перенаправляет authlib глобально. **Microsoft-вход заблокирован в
  таком запуске**. Для Microsoft используй отдельный профиль без agent.
- Это не способ обхода лицензии серверов Mojang. Offline-вход с кастомным UUID
  не является подтверждением владения соответствующим аккаунтом.
- OAuth предпочтительнее для будущего публичного релиза, но требует регистрации
  приложения Ely.by. Сейчас реализован документированный password+TOTP flow;
  никакие client secrets не встроены.
